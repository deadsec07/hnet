# hnet — Pentest Toolkit

hnet is a scriptable pentesting toolkit by A A Hasnat and HNE Technologies. It bundles utilities for network, web, wireless, exploitation, and small automation flows intended for authorized security testing and learning.

Links:
- PyPI: https://pypi.org/project/hnet-toolkit/
- GitHub: https://github.com/deadsec07/hnet
- Main site: https://hnetechnologies.com/
- Creator profile: https://deadsec07.github.io/

## Warning and ethics
- For authorized security testing only.
- Obtain explicit written permission before scanning or attacking systems you do not own.
- The maintainers disclaim liability for misuse.

## Quick start
- Linux/macOS:
  - `./scripts/install_dependencies.sh`
  - `./scripts/setup_virtualenv.sh`
- Windows (PowerShell):
  - `python -m venv venv`
  - `venv\Scripts\Activate.ps1`
  - `pip install -r requirements.txt`

## Package
- Package name: `hnet-toolkit`
- Install with `pip install hnet-toolkit` or `pipx install hnet-toolkit`

## Areas covered
- Network scanning and enumeration
- Web testing utilities
- Wireless tooling
- Exploitation helpers
- Automation helpers
